# Security

Do not post tokens, passwords, QR images, MFA codes, private histories, signed URLs or raw captures in issues. Use [GitHub private vulnerability reporting](https://github.com/BryanZaneee/Discut/security/advisories/new), which is enabled for this repository. If the private reporting control is unavailable, contact the repository owner through a contact they publish on their GitHub profile. Do not open a public issue containing exploit details; no dedicated email address or response-time guarantee is configured.

Use synthetic reproductions. The unofficial normal-user adapter is experimental and carries Discord account risk. No bot substitute, credential extraction from other applications, challenge bypass, telemetry or hidden messaging backend is supported. See docs/threat-model.md and docs/storage-policy.md.

The project does not yet promise production security support or full protocol compatibility. Dependency audit and platform release gates must pass before publishing a supported release.
